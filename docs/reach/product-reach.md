# LibraryFlow Product Reach

This file briefly summarizes the expected reach of the platform capabilities in a simple-to-understand way.

As with all other parts of the project, this file is subject to change.

## Users

There will be three user tiers: readers, publishers, and moderators.

Readers will be able to:

- Download books
- View books on the page
- Buy books
- Bookmark books
- Create book collections
- Comment on books
- Rate books on a five-star system with half stars
- Set their display name
- Set their personal information
- Set their profile picture
- Set their email address for account recovery
- Follow publishers
- Receive notifications
- Browse books with filters such as genre, author, publisher, publication date, and price
- Write their description
- Log in and out

Publishers will be able to:

- Upload books
- Add and modify book metadata and details
- Set prices for their books
- Tag their books by genre
- Set the maximum number of downloads per purchase

Moderators will be able to:

- Manage books across the platform
- Delete content
- Ban users
- Modify tags on books
- Send notifications to everyone
- Remove reviews
- Approve account creation

## What the Platform Will Do

The platform will primarily be developed for testing purposes, so actions such as buying, setting prices, and receiving payments will use a dummy system instead of a real transactional platform.

The platform will allow a limited number of downloads for users who have acquired a book. After reaching that limit, they must pay again to download the book or read it exclusively on the platform.

The platform will offer a reader for PDFs and EPUBs.

The platform will be entirely self-contained, so all information will be stored in the products of the developer.

The platform will be deployable to Render and Netlify.

It will include protections against attacks so the service does not become overwhelmed or shut down.
