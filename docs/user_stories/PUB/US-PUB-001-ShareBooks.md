# US-PUB-001 – Share books

## User Story

As a publisher, I want to share my books through the platform, so that readers can easily discover and access them.

## Acceptance Criteria

### CA-001 – Publish a valid book

Given that the publisher is authenticated and provides a title, author, description, and book content  
And the book is under 20 MB in size
When they submit the book  
Then the book must be stored on bucket storage and published  
And it must be visible in the public library.

### CA-002 – Require book information

Given that a required field is empty or invalid  
When the publisher submits the book  
Then the book must not be published  
And the missing or invalid field must be identified.

### CA-003 – Show public book details

Given that a book is published  
When a reader opens it  
Then the title, author, description, publisher, publication date, and access action must be shown.

### CA-004 – Preserve publisher ownership

Given that a publisher submits a book  
When the book is stored  
Then the authenticated publisher must be recorded as its owner.

### CA-005 – Allow publisher to manage their books

Given that a publisher is authenticated  
When they view their published books  
Then they must be able to edit or delete their own books

### CA-006 – Enforce moderation rules

Given that a book is published  
A moderator must approve public visibility before it is shown in the public library

### CA-007 – Enforce file size limit
Given that a publisher submits a book  
When the book exceeds 20 MB in size  
Then the book must not be published or stored in bucket storage
And the publisher must be notified that the file size exceeds the limit.

## Business rules

- **RN-001:** Only authenticated publishers may publish books.
- **RN-002:** Every published book must have a unique identifier.
- **RN-003:** Book metadata and content must persist between sessions.
- **RN-004:** A publisher may manage only books they own, subject to moderation rules.
- **RN-005:** The system must enforce a maximum file size limit of 20 MB for book uploads.
- **RN-006:** The name field can be repeted across different books, but the combination of name and author must be unique for each book.
- **RN-007:** The access key for a book must be unique and generated by the system upon successful publication based on the name and author.
- **RN-008:** Each book must have their own page with a unique URL that can be shared with readers, and the page must display the book's details and provide access to the book content, comment section, and rating section.

## Dependencies

- US-REA-010 must provide authentication.
- Persistent book metadata and file storage must be configured.

## Out of Scope

* Payments
* Copyright verification
* Collaborative editing
* Automatic content moderation
