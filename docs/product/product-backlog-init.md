# LibraryFlow Product Backlog

Initial proposal of the backlog using the format from the previous last project.

## Backlog overview

| Priority | Items |
|---|---:|
| Essential for MVP | PB-001 to PB-007 |
| Later | PB-008 to PB-014 |

## MVP backlog

These items are considered essential for the first usable version of the product.

| ID | Capability | Priority | Related users | Value |
|---|---|---|---|---|
| PB-001 | Register and log in | Essential for MVP | Readers | Allows readers to access the digital library protecting from bad actors. |
| PB-002 | Publish and share books | Essential for MVP | Publishers | Gives publishers a way to make their books available to readers. |
| PB-003 | View and search books | Essential for MVP | Readers, Publishers | Helps users discover books through the library. |
| PB-004 | Maintain book details and metadata | Essential for MVP | Publishers | Keeps book information accurate and useful. |
| PB-005 | Classify books by category and genre | Essential for MVP | Publishers, Moderators | Keeps the library organized and improves discovery. |
| PB-006 | Comment on books | Essential for MVP | Readers, Publishers | Creates a community around the books. |
| PB-007 | Download and read books offline | Essential for MVP | Readers | Allows readers to access purchased or available books without a connection or drm apps. |

## Extra backlog

These items are planned for a later stage.

| ID | Capability | Priority | Related users | Value |
|---|---|---|---|---|
| PB-008 | Create and manage book collections | Later | Readers, Publishers | Helps users organize related books and series. |
| PB-009 | Save books to favorites | Later | Readers, Publishers | Makes it easier to return to keep track of books. |
| PB-010 | Notify users about favorited book updates | Later | Readers, Publishers | Keeps users informed about new chapters and changes. |
| PB-011 | Rate books | Later | Readers | Provides useful feedback to users about books. |
| PB-012 | Follow publishers | Later | Readers | Helps readers keep up with publishers they are interested in. |
| PB-013 | Moderate content and users | Later | Moderators | Keeps the platform safe, and useful. |
| PB-014 | Set book prices and use a dummy purchase flow | Later | Publishers, Readers | Supports testing of the platform's publishing and purchasing flow without real payments. |

## Planning notes

> [!NOTE]
> Purchasing, pricing, and payment are represented by a dummy system for testing.

- **Scalability:** It should be scalable into a real product.
- **Before each sprint:** Review the priority of each item.
- **Before implementation:** Define acceptance criteria.
- **Execution:** The system must be ready for deployment but also testable in a local environment.
